# Roadmap

Where CompanySystem is and where it's heading.

## ✅ Done

- **Authentication** — JWT login, roles, per-role access control.
- **Employees** — directory + grant/revoke login access.
- **Store / Items** — materials with low-stock alerts.
- **Projects** — full CRUD, unique codes, statuses.
- **Documents & Approvals** — upload Excel, Engineer → Manager → CEO pipeline, approve / return / reject / resubmit, file storage + authenticated download.
- **Notifications** — persistent, two-directional, near-live bell.
- **Document trace / timeline** — 3-step stepper + full event history.
- **Polish** — bilingual EN/AR with RTL, dark/light theme, correct UTC timestamps.

## 🔜 Next up

- **Phase B — Suppliers & Purchases** — who the company buys from and at what price. This is the foundation for **cost-per-project** reporting.

## 💡 Later ideas

- Item **photo upload**.
- **Excel import** to bulk-create items.
- **Purchases & Sales statistics** dashboard.
- Printable **stock-movement records** ("processes").

---

*This is a learning project, built one focused step at a time. Each feature ships as a small set of commits with a clear scope.*
